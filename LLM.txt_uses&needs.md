# LLM.txt - Beginner Notes

## What is LLM.txt?

LLM.txt is a plain text file that helps Large Language Models (LLMs)
understand the structure and most important content of a website. It
acts as a guide for AI systems, especially on documentation-heavy
websites.

## Why is it Needed?

Large websites often have: - Thousands of documentation pages - API
references - Tutorials - Blogs - FAQs

Instead of searching every page, an AI can read `llm.txt` first to find
the most relevant sections.

## Example

A documentation website contains: - 2,000 API pages - 500 tutorials -
300 blog posts

If a user asks, "How do I authenticate with the API?", the AI can read
`llm.txt`, locate the API documentation, and retrieve only the relevant
pages.

## Typical Contents

-   Website overview
-   Documentation sections
-   API references
-   Tutorials
-   Important links
-   Recommended starting pages

## AI Workflow

User Question → AI Assistant → Read llm.txt → Find relevant
documentation → Retrieve useful pages → Generate answer

## Benefits

-   Faster navigation
-   Better retrieval quality
-   Less unnecessary searching
-   Useful for AI agents and RAG systems
-   Helps organize large documentation websites

## LLM.txt vs Other Website Files

  File          Purpose
  ------------- ---------------------------------------
  robots.txt    Controls crawler access
  sitemap.xml   Lists website URLs
  llm.txt       Guides AI models to important content

## Where is LLM.txt Used?

-   Documentation websites
-   API documentation
-   Developer portals
-   Knowledge bases
-   Product documentation

## Key Takeaways

-   LLM.txt is designed for AI systems.
-   It acts as a guide rather than a database.
-   It is especially useful for websites with hundreds or thousands of
    pages.
-   It helps AI systems retrieve the right information more efficiently.
